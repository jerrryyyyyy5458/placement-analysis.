Placement Analysis – EDA Mini Project
Project Overview
This project focuses on Exploratory Data Analysis (EDA) of placement-related data using Tableau. The objective is to analyze placement trends, identify patterns, and gain meaningful insights into student placement outcomes through interactive data visualizations.
Objectives

Analyze student placement trends and patterns.
Explore relationships between academic performance and placement outcomes.
Identify factors that may influence placement opportunities.
Present meaningful insights through data visualization.

Tools & Technologies

Tableau: Data visualization and dashboard creation.
Dataset: Placement-related dataset.
Exploratory Data Analysis (EDA): Data exploration and pattern identification.

Project Workflow

Imported the placement dataset into Tableau.
Explored and analyzed the dataset.
Created visualizations to identify trends and patterns.
Designed a Tableau workbook to present the analysis.
Derived insights from the visualized data.


Key Learnings

Hands-on experience with Tableau.
Understanding of exploratory data analysis.
Data visualization and interpretation.
Identifying trends and patterns in placement data.

How to View the Project

Download the edamini.twb file from this repository.
Open it using Tableau Desktop.
If prompted, connect the original dataset.
Explore the worksheets and dashboards.
